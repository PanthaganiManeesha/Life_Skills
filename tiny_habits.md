## Question 2
### How can you use B = MAP to make making new habits easier? What are M, A and P?

B = MAP means:

- **B = Behavior**
- **M = Motivation**
- **A = Ability**
- **P = Prompt**

Habits become easier when they are simple, easy, and connected with reminders.

### Example
- **Motivation:** Gain knowledge  
- **Ability:** Read one page  
- **Prompt:** Read after dinner

## Question 6
### Write about the book's perspective on how to make a habit easier to do.

### Ways

- Prepare in advance
- Break tasks into smaller steps

## Question 7
### Write about the book's perspective on how to make a habit harder to do.

Bad habits become weaker when they are difficult to access.

### Ways
- Remove triggers
- Add obstacles
- Use limits or restrictions
